## 手机端

手机、平板及折叠屏会随可用宽度调整布局。以下截图展示主要入口与操作。

### 首次使用与导航

- 底部切换“搭配码、家园方案、相机参数、暖暖档案”。
- 顶部放大镜搜索当前模块，视图按钮调整显示、主题与语言；顶部“更多”提供解析工具、抽卡吉时、全部数据备份及帮助。
- 页面“+”添加数据，“⋯”管理本模块；标签或星级入口用于筛选。大图支持左右滑动、双指缩放和拖动查看。
- 相册目录管理、自动读取游戏搭配与专项清理请在电脑端使用。

### 搭配码

保存搭配图片与分享码，随时复制、编辑或解析。

<div align="center">
  <img src="img/page/outfits.webp" alt="手机搭配码列表与部件染色详情" width="70%">
  <p><sub>搭配码列表与部件详情</sub></p>
</div>

- 点页面“+”添加图片、搭配码、备注和标签；搭配码可留空，稍后补充。
- 卡片底部提供复制、编辑、删除和解析；未填写码时复制与解析不可用，双击卡片可看大图。
- 点标签入口筛选或管理标签，点页面“⋯”导入／导出本模块 ZIP。

### 家园方案与相机参数

**家园方案**

- 点“+”输入家园码或组合码，解析后填写名称、封面、备注和标签并保存。
- 卡片底部提供复制、编辑和删除；可按码类型或标签筛选，双击卡片查看大图。

**相机参数**

- 点“+”输入参数码，解析成功后填写名称并保存，可添加封面和标签；也可从照片解析结果收藏。
- 卡片底部提供复制、编辑、删除和详情；复制出的参数码可在游戏相机中导入。

两类收藏均从页面“⋯”菜单导入／导出 ZIP。删除标签只移除分类，不删除对应记录。

## 电脑端

### 首次使用与导航

使用电脑上的 Chrome、Edge 或兼容的 Chromium 浏览器。左侧切换模块并筛选，顶部搜索当前模块；“视图”调整显示、主题与语言，“工具”打开解析和辅助功能，“更多”提供全部数据备份与帮助。

### 相册浏览、照片解析与最近删除

按日期或动作浏览游戏照片，查看大图、收藏照片并解析拍摄参数。

点击“选择/恢复相册路径”，推荐直接选择以下目录，不要选择磁盘根目录、Program Files 或游戏安装上级目录：

```text
...\InfinityNikki Launcher\InfinityNikki\X6Game\Saved\GamePlayPhotos\你的ID\NikkiPhotos_HighQuality
```

#### 兼容打开（只读）

如果普通授权无法打开游戏相册，可在“当前相册”菜单或相册空白页点击“兼容打开（只读）”，选择直接存放照片的文件夹。此方式只读取本次选择的文件，不会上传照片，也不修改原目录。

- 支持浏览、筛选、大图、收藏、参数解析和查看已有备注；没有 X6Game 授权时可手动输入 UID 解析参数。
- 仅展示根目录图片，不混入子目录或 `trash` 图片。导出通过 ZIP 下载，包含照片和备注，按每包不超过 128 MiB 分包；单张图片上限 64 MiB。
- 导入原目录、编辑备注、删除、恢复和专项清理不可用；需要这些操作时切回普通目录授权模式。
- 点击“重新选择文件夹”获取新照片；刷新网页或下次打开也需要重选。取消、空文件夹或读取失败会保留当前已打开的相册。普通模式保存的目录授权仍保留。
- 收藏按相对路径、大小和修改时间识别照片；元数据完全相同的同名文件夹副本无法区分，兼容模式与普通模式的照片收藏标记独立。相册原图不会被持久化到浏览器。

#### 照片操作

| 操作 | 结果 |
| --- | --- |
| 单击照片 | 选中或取消选中 |
| 双击照片 | 打开大图预览 |
| 点击爱心 | 加入或移出收藏夹 |
| 点击左侧日期 | 跳转到对应日期 |
| 左右方向键 | 在大图预览中切换照片 |
| 滚轮 / 缩放按钮 | 在大图预览中按 25% 步长缩放 |
| 拖动大图 | 放大后移动图片查看细节 |
| `Esc` | 关闭大图预览 |
| `Delete` | 将当前预览照片移到最近删除 |
| 底部操作栏 | 全选、批量收藏、删除、恢复或永久删除 |
| 导入图片 | 选择多张本地图片并复制到当前相册 |
| 导出全部图片 | 将当前相册全部图片复制到指定文件夹并显示进度 |
| 底栏导出 | 将选中的图片复制到指定文件夹 |

> 普通相册删除会把原图移动到当前相册的 `trash` 文件夹；<span style="color: red;">最近删除中的“永久删除”和“专项清理”会直接删除电脑文件，无法恢复。</span>

#### 最近删除与刷新

- 点击“刷新相册”可立即同步文件夹；页面重新获得焦点时也会自动同步，并提示新增或外部移除的照片。
- 最近删除按删除时间排序，顶部显示照片总数和总大小；支持单张或批量恢复、永久删除、全选、大图预览和清空全部。
- 恢复时若原相册已有同名文件，会自动使用 `_restored_1`、`_restored_2` 等后缀，不会覆盖现有照片。
- 最近删除不会自动过期，会一直保留到手动恢复或永久删除。

#### 专项清理

点击右上角“工具”菜单中的“专项清理”打开清理窗口，使用清理功能需要授权 `X6Game` 文件夹。

支持以下清理项：

- 低画质图片和截图（`...\X6Game\ScreenShot` 与 `NikkiPhotos_LowQuality`）：游戏拍照后产生的画质较低的图片，仅删除图片文件。存在多个账号文件夹时，可选择清理全部账号或指定账号 ID。如果当前管理的相册本身是 `ScreenShot` 或 `NikkiPhotos_LowQuality`，本次清理会跳过该相册目录、只清理另一个目录，并在确认提示中说明，建议管理 `NikkiPhotos_HighQuality` 相册。
- 游戏崩溃时的快照信息（`...\X6Game\Saved\Crashes`）：删除后将无法通过本地日志向官方反馈历史崩溃原因。
- 游戏运行日志（`...\X6Game\Saved\Logs`）：删除后无影响。
- 游戏内置浏览器与登录器缓存（`...\X6Game\Saved\webcache_4430`）：清理过期网页数据，但初次打开活动页面或公告时会加载变慢。

其他工具可从“工具”菜单进入；“更多”提供使用帮助、更新记录与问题反馈。

## 备份与迁移

在“更多”中选择“导出全部数据”，下载的 ZIP 包含搭配方案、家园方案、相机收藏、共鸣记录和个人衣橱，以及已保存的方案图片与封面。将 ZIP 传到另一台设备，再通过“导入全部数据”恢复。**游戏相册原图不包含在内，请另行备份。**

不同导入入口对已有记录的处理不同：

| 入口 | 对已有记录的影响 |
| --- | --- |
| 暖暖档案 → 添加数据 | 核对预览并选择模块，确认后整份替换勾选模块；预览未包含的旧记录会移除。 |
| 更多 → 导入全部数据 | 按各模块规则合并；相机参数冲突时选择保留方式，不是整份覆盖。 |
| 搭配码模块 → 导入数据 | 添加方案，不覆盖已有方案，重复或无效内容会跳过。 |

共鸣与衣橱共用一个云同步窗口，从任一页面的“云端”进入均可处理两个模块。上传和下载默认勾选可用模块，也可取消其中一项；删除云端存档需明确勾选范围。采用覆盖方式：**上传以所选模块的全部本地记录覆盖对应云端存档，下载以所选云端完整存档覆盖对应本地记录。**目标端独有记录会移除，不受页面筛选影响；未选中的模块保持原样。两个模块一起操作时共同提交，任一模块版本冲突或提交失败都不覆盖目标。账号、存档格式和各模块版本保持兼容。衣橱区服随存档恢复，区服不同时会提示；有效的 0 件衣橱可以同步，未导入或清空后的状态不能上传，云端无存档不会清空本地。

衣橱中的“未记录”表示手账未返回该散件，不代表游戏中未拥有。仅含共鸣记录的导出文件不能用于导入衣橱。

## 常见问题

### 通用问题

#### 图片无法选择或保存

可重新选择图片重试；替换失败时会保留原图。支持 WebP、PNG、JPEG 等常见格式，HEIC/HEIF 取决于浏览器支持情况，无法使用时可先转为 PNG 或 JPEG。

#### 照片参数无法解析

请使用游戏原图，裁剪、压缩或转存可能丢失解析所需的数据。提示输入 UID 时，请填写拍摄这张照片所用账号的 UID。

#### 图鉴图片或详情加载失败

有重试入口时可点击重试；持续失败时，请检查网络后刷新页面。

### 电脑相册与本地启动

#### 启动器没有反应

- 确认项目已经完整解压，不要在 ZIP 内运行。
- 确认已安装 Node.js 22 或更高版本的 LTS，且 `start` 文件夹没有缺失。
- 检查安全软件是否拦截 EXE 或 BAT 文件。
- 也可直接运行 `start\Start-Remote-D1-Website.bat` 查看错误信息。

#### 网页没有显示照片

- 确认选择的是实际图片目录。
- 确认文件扩展名受支持；文件名以日期格式开头时会优先按文件名整理，其他图片会按文件最后修改时间显示。
- 浏览器授权失效时，重新点击“选择/恢复相册路径”。

#### 浏览器拒绝打开文件夹

浏览器会阻止网页访问系统目录。请直接选择 `NikkiPhotos_HighQuality`，<span style="color: red;">不要选择磁盘根目录或游戏安装上级目录。</span>

## 隐私与安全

- 本地照片浏览和照片参数解析在浏览器中完成，不上传照片或照片参数解析结果。
- 搭配码解析会将分享码发送给解析服务，不发送本地照片或手账凭据。
- 云同步支持共鸣记录和个人衣橱，可在同一窗口勾选后一起手动上传或下载。其他模块保存在当前浏览器，更换设备或清理网站数据前请先备份。
- “清除缓存”仅删除解析缓存，不删除已保存的方案、标签和设置。**“清除数据”会永久移除当前浏览器中的记录、图片、收藏、设置及目录授权，请先导出备份。**它不会删除已上传的云端存档或电脑文件；通过浏览器设置清除网站数据还可能移除登录信息。
- 浏览器可能要求重新授权文件夹。
- 相册删除和专项清理会操作电脑中的真实文件；永久删除及专项清理无法恢复。

## 本地安装

环境要求：Windows、[Node.js 22 或更高版本的 LTS](https://nodejs.org/)、电脑上的最新版 Chrome、Edge 或其他兼容的 Chromium 浏览器。

### 安装 Node.js

1. 打开 [Node.js 官网](https://nodejs.org/)，下载 22 或更高版本、标有 **LTS** 的 Windows 安装包，不要选择 Current 版本。
2. 双击安装包，保持默认选项并继续安装；确保 `Add to PATH` 相关选项没有被取消。
3. 安装完成后关闭并重新打开终端、项目文件夹和启动器窗口，让环境变量生效。
4. 按 `Win + R`，输入 `cmd` 并回车，然后分别运行：

```bash
node -v
npm -v
```

两个命令都能显示版本号，说明安装成功。如果提示“不是内部或外部命令”，请重启电脑后再试；仍然失败时，卸载 Node.js 并重新安装 LTS 版本。

### 本地部署

1. 从 [GitHub Releases](https://github.com/sumopenny/Infinity-Nikki-Toolkit/releases) 或 [Gitee Releases](https://gitee.com/sumopenny/Infinity-Nikki-Toolkit/releases) 下载并解压项目，或从仓库克隆源码。
2. 双击根目录的 `网站启动器.exe`。
3. 首次运行会自动安装依赖；资源更新结束且开发服务器成功开始监听后，才自动打开 `http://localhost:5173`。更新过程中不会提前打开网页；若启动失败或端口被占用，不会打开浏览器，请查看开发服务器窗口中的错误提示。
4. 使用期间不要关闭窗口。

启动器不可用时，可运行 `start\Start-Remote-D1-Website.bat`，或使用下方命令手动启动。启动时需要联网更新资源，更新失败时沿用已有本地资源。

本地运行的点赞、共鸣账号及云同步连接线上服务，相关操作会影响真实线上数据。默认服务地址为 `https://infinity-nikki-album-manager.pages.dev`。

### 开发命令

在项目根目录执行：

```bash
npm install                # 安装依赖
set REMOTE_API_ORIGIN=https://infinity-nikki-album-manager.pages.dev
npm run dev:remote         # 连接线上服务并启动本地网站
npm test                   # 运行自动化测试
npm run build              # 类型检查并构建
npm run build:cloudflare   # 更新资源并构建 Cloudflare 版本
npm run preview            # 预览构建结果
```
