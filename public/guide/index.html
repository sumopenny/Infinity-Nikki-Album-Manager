电脑和手机怎么开始？

  1. 打开工具首页。选择要使用的模块；介绍页中的按钮都进入同一个工具首页。
  2. 电脑管理本地相册。使用支持目录授权的浏览器，选择游戏照片文件夹。相册目录管理和文件清理需在电脑上使用。
  3. 手机整理方案与记录。通过底部导航进入搭配码、家园方案、相机参数或共鸣记录，从各模块菜单进行导入导出。

数据保存在什么地方？

照片在本地浏览器中读取。方案、收藏和共鸣记录等数据与当前浏览器有关，建议定期导出备份。共鸣云同步为可选功能：需要主动上传或下载，登录账号不会自动同步，也不会上传本地照片。

打开暖立方工具集

视图设置、小工具与帮助

  • 界面设置：工具支持中文与 English、浅色与深色主题，以及视图菜单中的缩略图设置；部分选项按设备与当前模块提供。
  • 抽卡吉时：工具菜单提供时间表与推荐，仅作娱乐参考，不会改变游戏实际概率。
  • 使用帮助与更新：“更多”中可查看帮助介绍、更新记录，遇到问题可打开反馈问卷。
  • 支持与交流：工具界面提供点赞、打赏、作者社交平台、GitHub/Gitee 仓库和官方网站入口。
  • 本地运行：可下载或克隆本项目，在 Windows 电脑上按 README 安装环境并使用启动器；也可以直接使用在线工具。
