## 功能

### 相册浏览

按日期浏览照片，支持大图预览、收藏、备注搜索和批量导入导出。

### 搭配码与参数解析

管理搭配与家园方案，解析搭配码和照片参数，支持标签分类及 ZIP 备份。

### 共鸣记录

导入、查看和统计共鸣记录，支持 JSON 导入导出及账号云同步。

电脑布局（≥900px）保留左侧套装立绘，右侧上下同时展示第一套和第二套；每套的已记录抽数与已知部件均抽位于对应部件上方，窄窗口允许部件换行，无需切换套数。标题下仍显示两套合计的总抽数与平均抽数。

### 文件清理

清理低画质图片、游戏截图、崩溃快照、日志和缓存。

### 小工具与帮助

提供抽卡吉时、更新记录、使用帮助和问题反馈。

## 手机使用

- 底部导航切换搭配码、家园方案、相机参数和共鸣记录；相册目录授权与文件清理需在电脑上使用。
- 顶部提供搜索、视图设置和“更多”；标签或星级入口用于筛选，“+”用于添加，“⋯”菜单提供导入导出等操作。
- 手机端四个模块没有数据时，在说明文字下展示对应使用截图，原空状态导入按钮移除，仍可从“⋯”菜单导入；搜索或筛选无结果时不展示截图，电脑端不变。截图素材依次放在 `img/page/outfits.webp`（搭配码）、`img/page/home.webp`（家园方案）、`img/page/camera.webp`（相机参数）、`img/page/resonance.webp`（共鸣记录）。图片完整等比显示，缺图或加载失败时隐藏；新增或替换素材后需重新构建部署。
- 大图支持左右滑动翻页、双指缩放和拖动查看。
- 共鸣记录可手动上传云端，再在另一设备登录同一账号同步；登录和本地修改不会自动同步。
- 移动布局（≤899px）的共鸣卡片使用小立绘摘要与全宽部件网格，常规五列、窄于 360px 时四列。摘要中的卡池名下方、获得进度上方显示原口径的两套总抽数和平均抽数，切换套数时保持不变，窄屏可换行。部件上方可切换第一套/第二套，获得进度、已记录抽数和已知部件均抽随当前套变化；补录只计入获得进度，无已知抽数时显示“—”。
- 搭配、家园和相机收藏可在电脑导出全部数据 ZIP，手动传到手机后导入。

## 搭配码管理
电脑端进入“搭配码”后会按用户偏好显示独立操作指南，也可从标题旁的指南按钮打开；手机端不展示指南入口或自动弹出指南。
- 最多可创建 40 个用户标签，每个标签不超过 5 个字符。删除使用中的标签只会让相关方案归入“未分类”。
- 新增标签会显示在标签列表首位；可拖动左侧手柄调整顺序。
- 点击“添加方案”可以选择、拖拽或粘贴图片（点击窗口空白处后按 `Ctrl+V`）；JPG 和 PNG 会在本地转换为 WebP，搭配码允许留空，标签最多选择一个，双击图片可打开预览。
- 电脑端搭配卡片右上角显示解析按钮，手机端从卡片底部解析按钮进入解析；未填写搭配码时按钮保持禁用。删除按钮位于解析按钮左侧，并在悬停卡片或键盘聚焦时显示。
- 可从右上角“工具”菜单打开“参数/搭配码解析”窗口，直接输入搭配码，无需先创建搭配方案；解析结果复用同一个搭配码解析窗口。
- 搭配方案大图预览的底部工具栏会显示当前标签和搭配码，并提供复制与编辑按钮。
- 搭配码、图片、备注和标签保存在当前浏览器中，所有相册共用，无需创建相册内的 `clothe` 文件夹。批量迁移请使用模块 ZIP 或“导入全部数据”。
- 选择相册后会自动迁移旧 `clothe` 数据；全部迁移成功且源文件未变化时才清理旧目录。损坏数据、未关联图片和未知文件会保留并提示，不会把散图自动转为方案。
- 使用<span style="color: orange;">自动更新搭配码</span>功能需要授权当前游戏的 `X6Game` 文件夹，可前往页面右上角当前相册下拉菜单进行授权。<span style="color: red;">使用方式是：在游戏内点击分享按钮，需要在搭配截图右下角点击框选按钮，框选完成后点击生成搭配码，再返回网页。网站只有在检测到新搭配码且游戏搭配图片的最后修改时间也已更新时才会导入；已有相同搭配码、图片未更新或找不到图片时会跳过并提示。</span>

<div align="center">
  <img src="img/自动更新步骤.webp" alt="游戏内自动更新搭配码的操作步骤" width="70%">
</div>

- “导出数据”通过浏览器下载 ZIP 备份，保存位置由浏览器下载设置决定，无需选择相册目录；数据较多时会生成多个 ZIP，请允许多文件下载。备份保留搭配码、标签、备注和创建时间。“导入数据”不会覆盖已有方案，重复或无效内容会跳过；导入会先校验完整备份，再分批解压和写入图片，减少大备份占用的浏览器内存。
- JPG、PNG 和 WebP 在保存前只解码校验一次；JPG、PNG 仍会在本地转换为 WebP，整个过程不会上传图片。
- 单击搭配方案可进行多选并显示底部工具栏，<span style="color: red;">搭配方案删除后不可恢复，确认前请核对方案信息。</span>

## 专项清理

点击右上角“工具”菜单中的“专项清理”打开清理窗口，使用清理功能需要授权 `X6Game` 文件夹。

支持以下清理项：

- 低画质图片和截图（`...\X6Game\ScreenShot` 与 `NikkiPhotos_LowQuality`）：游戏拍照后产生的画质较低的图片，仅删除图片文件。存在多个账号文件夹时，可选择清理全部账号或指定账号 ID。如果当前管理的相册本身是 `ScreenShot` 或 `NikkiPhotos_LowQuality`，本次清理会跳过该相册目录、只清理另一个目录，并在确认提示中说明，建议管理 `NikkiPhotos_HighQuality` 相册。
- 游戏崩溃时的快照信息（`...\X6Game\Saved\Crashes`）：删除后将无法通过本地日志向官方反馈历史崩溃原因。
- 游戏运行日志（`...\X6Game\Saved\Logs`）：删除后无影响。
- 游戏内置浏览器与登录器缓存（`...\X6Game\Saved\webcache_4430`）：清理过期网页数据，但初次打开活动页面或公告时会加载变慢。

## 选择相册

点击“选择/恢复相册路径”，推荐直接选择：

```text
...\InfinityNikki Launcher\InfinityNikki\X6Game\Saved\GamePlayPhotos\你的ID\NikkiPhotos_HighQuality
```

不要选择 C 盘、Program Files、游戏安装根目录等受保护或过大的上级目录。

## 最近删除与刷新

- 点击“刷新相册”可立即同步文件夹；页面重新获得焦点时也会自动同步，并提示新增或外部移除的照片。
- 最近删除按删除时间排序，顶部显示照片总数和总大小；支持单张或批量恢复、永久删除、全选、大图预览和清空全部。
- 恢复时若原相册已有同名文件，会自动使用 `_restored_1`、`_restored_2` 等后缀，不会覆盖现有照片。
- 最近删除不会自动过期，会一直保留到手动恢复或永久删除。


## 常见问题

### 启动器没有反应

- 确认项目已经完整解压，不要在 ZIP 内运行。
- 确认已安装 Node.js 22 或更高版本的 LTS，且 `start` 文件夹没有缺失。
- 检查安全软件是否拦截 EXE 或 BAT 文件。
- 也可直接运行 `start\Start-Remote-D1-Website.bat` 查看错误信息。

### 网页没有显示照片

- 确认选择的是实际图片目录。
- 确认文件扩展名受支持；文件名以日期格式开头时会优先按文件名整理，其他图片会按文件最后修改时间显示。
- 浏览器授权失效时，重新点击“选择/恢复相册路径”。

### 浏览器拒绝打开文件夹

浏览器会阻止网页访问系统目录。请直接选择 `NikkiPhotos_HighQuality`，<span style="color: red;">不要选择磁盘根目录或游戏安装上级目录。</span>

## 隐私与安全

- 照片在本地浏览器中读取。
- 共鸣云同步连接本站 Pages 服务；手动上传会将共鸣记录保存到云端 D1，不上传本地照片。其他模块的记录仍由浏览器保存，云同步只覆盖共鸣。
- 照片尾段、账号密钥派生、AES 解密和 CameraParams 解析均在本地 WASM 中执行，照片和解析结果不会上传。
- 相册目录授权、收藏记录、搭配码、家园方案码和照片动作解析缓存保存在当前浏览器本地；“更多”里的“清除缓存”会清除这三类解析缓存，不影响其他授权或设置，也不会删除已保存的方案和标签。“清除数据”经确认后永久删除当前浏览器中的全部方案、图片、标签、共鸣记录、收藏、解析缓存、UID、所有保存的目录句柄、游戏来源和迁移记录，并清空网站本地及会话设置，自动重新加载回到各端初始状态；此操作无法撤销，请先导出备份。该操作保留云端账号和存档，不会主动退出云端登录。浏览器自身清除站点数据也可能删除本地记录和登录凭据；云端已上传的存档保留。
- 浏览器可能因安全策略要求重新授权文件夹。
- 删除和专项清理会修改电脑中的真实文件；“清除缓存”和“清除数据”不会删除电脑里的文件。

## 本地安装


环境要求：Windows、[Node.js 22 或更高版本的 LTS](https://nodejs.org/)、电脑上的最新版 Chrome、Edge 或其他兼容的 Chromium 浏览器。

### 安装 Node.js

1. 打开 [Node.js 官网](https://nodejs.org/)，下载 22 或更高版本、标有 **LTS** 的 Windows 安装包，不要选择 Current 版本。
2. 双击安装包，保持默认选项并继续安装；确保 `Add to PATH` 相关选项没有被取消。
3. 安装完成后关闭并重新打开终端、项目文件夹和启动器窗口，让环境变量生效。
4. 按 `Win + R`，输入 `cmd` 并回车，然后分别运行：

```bash
node -v
npm -v
```

两个命令都能显示版本号，说明安装成功。如果提示“不是内部或外部命令”，请重启电脑后再试；仍然失败时，卸载 Node.js 并重新安装 LTS 版本。

### 本地部署

1. 从 [GitHub Releases](https://github.com/sumopenny/Infinity-Nikki-Album-Manager/releases) 或 [Gitee Releases](https://gitee.com/sumopenny/Infinity-Nikki-Album-Manager/releases) 下载并解压项目，或从仓库克隆源码。
2. 双击根目录的 `网站启动器.exe`。
3. 首次运行会自动安装依赖；资源更新结束且开发服务器成功开始监听后，才自动打开 `http://localhost:5173`。更新过程中不会提前打开网页；若启动失败或端口被占用，不会打开浏览器，请查看开发服务器窗口中的错误提示。
4. 使用期间不要关闭窗口。

本地启动统一使用远程 D1 模式，不再提供不带 D1 的独立启动脚本。启动器不可用时，可双击 `start\Start-Remote-D1-Website.bat`，或使用下方开发命令手动启动。根目录的 `网站启动器.exe` 也会连接这个远程 D1 启动脚本。

本地页面通过远程 D1 模式读取线上数据，可双击 `start\Start-Remote-D1-Website.bat`。点赞及共鸣账号、云同步请求会在本地转发到线上 Pages，不会让浏览器直接接触 D1；搭配码、家园方案数据和 Gongeo 图鉴详情由本地 Vite 直接代理到上游服务。生产部署通过 `functions/api/gongeo/[[path]].ts` 和 `functions/api/home-build/[key].ts` 提供同源数据代理。点赞、共鸣注册、上传和删除会操作目标站点的真实云端数据，请先核对站点地址。脚本默认使用 `https://infinity-nikki-album-manager.pages.dev`，也可把其他 Pages 地址作为脚本参数传入。

### 开发命令

内部流程由 `useOperationCoordinator` 统一登记模块任务，`useLatestRequest` 管理异步读取失效；`useDirectorySession` 与 `useOutfitWorkspace` 分别负责目录授权和搭配操作，家园/搭配共用 `file-system/transaction.ts` 的提交与回滚机制。动作资源请求的超时覆盖响应正文读取。

开发与本地 Pages/D1 命令使用开发依赖中精确固定的 Wrangler 4.149.0，需 Node.js 22 或以上；建议用 `npm ci` 按 lockfile 安装。`dev:pages`、`d1:migrate:local` 和 `d1:migrate:remote` 不再临时下载 latest 版本。

所有手写 Vue、TypeScript、CSS、资源脚本、测试和启动依赖脚本共用固定版本 Prettier：`npm run format` 格式化，`npm run format:check` 检查；旧 `format:review` 命令保留为兼容别名。生成图鉴 JSON、依赖锁文件和构建产物不参与格式化。公共按钮、菜单及减少动态效果规则集中在 `src/styles/controls.css`。

家园操作错误按权限、存储空间、图片、数据和标签冲突分别提示；控制台仅记录操作名及错误类别，不记录原始异常内容或凭据。共鸣导航子菜单随中英文切换。

```bash
npm install       # 安装依赖
set REMOTE_API_ORIGIN=https://infinity-nikki-album-manager.pages.dev
npm run dev:remote # 更新动作、灯光/滤镜、部件目录和共鸣录映射目录；搭配码和家园方案走对象存储代理，其余 /api 走线上 Pages
npm test          # 运行自动化测试
npm run build     # 类型检查并构建
npm run build:cloudflare # 刷新普通动作、灯光/滤镜、部件目录和共鸣录映射目录后构建
npm run resources:update:light-filters # 单独检查灯光/滤镜更新
npm run preview   # 预览构建结果
```

本地 EXE 启动器、`dev`、`dev:remote` 和 Cloudflare 构建共用资源更新链。灯光/滤镜检查暖暖相册远程热更新清单中的数据库和中英文语言包版本，版本变化时下载并校验；仅替换灯光/滤镜名称、ID 映射和图片模板，保留普通动作与大喵数据。版本相同不下载资源文件；失败时提示并沿用已有快照。普通 `npm run build` 只做类型检查和构建。

启动资源更新会优先检查 HTTPS_PROXY/HTTP_PROXY（含小写变量），再读取 Windows 已启用的手动系统代理；只使用可连接的本机 HTTP/HTTPS 代理，不扫描常见端口。未配置或未启动时直连；代理请求连接失败或超时后只再直连一次，并在本进程后续请求中使用直连。HTTP 错误和数据校验失败不重试，更新仍失败时保留本地资源并继续启动（显式 --strict 模式仍报错）。遵循 NO_PROXY，本地地址默认直连。检测只作用于资源更新请求，不修改系统代理、npm 配置或网站 API 转发；PAC/SOCKS 不参与自动检测。

灯光/滤镜脚本支持 `--force` 强制刷新、`--strict` 在失败时终止，以及 `--manifest <URL>` / `--timeout <毫秒>`；也可用 `NUAN5_HOT_UPDATE_MANIFEST` 指定远程清单 URL、`NUAN5_HOT_UPDATE_TIMEOUT_MS` 设置超时（默认 15000 毫秒）。通过 npm 传参时在选项前加 `--`。

物品图鉴本地生成需显式传入 Gongeo 仓库目录（或设置 `GONGEO_ROOT`），例如 `node scripts/generate-item-catalog.cjs "C:/path/to/gongeo"`；远程同步继续使用 `npm run resources:update:items`。重建启动器时，`start/launcher/Build-Launcher.ps1` 先编译临时文件，成功后替换启动器；编译失败保留旧启动器。

技术栈：Vue 3、TypeScript、Vite、File System Access API、IndexedDB。

部分功能借鉴并使用了 [暖暖相册](https://github.com/RanAxro/nikki_albums) 和 [共鸣录](https://github.com/dastrokes/gongeo.us-nikki-tracker) 的相关服务。本项目许可证请参阅根目录的 [LICENSE](LICENSE) 文件。

图片诊断：搭配图片预览或保存失败时，错误信息包含失败阶段、文件类型、字节数及浏览器版本；控制台保留原始异常。img 加载事件不提供底层原因，因此诊断信息不代表已确定根因。

解码失败后会额外执行 FileReader / Data URL 诊断，报告读取字节数、文件头、SHA-256 和 Data URL 加载结果（仅诊断，不作为保存兜底）；读取和加载各最多等待 15 秒。


搭配图片现在在选中时立即读取并生成内存副本，预览和保存均使用副本，避免手机原文件引用随后失去可读性。读取时显示“正在读取图片…”并暂停确认；读取失败需重新选择。此前临时的选中/保存重复读取对照已移除，失败阶段诊断保留。

图片内存副本处理仅在移动布局（窗口宽度 ≤899px）启用；桌面布局（≥900px）选图后直接预览并保存原文件，不提前读取副本。按选图时的布局决定处理方式。

相机参数收藏的封面上传同样仅在移动布局选中时复制为内存文件；读取期间暂停保存，失败提示重选，重选或关闭后丢弃旧任务结果。桌面布局仍直接使用原文件。

相机参数收藏读取封面时，“正在读取图片…”在顶部操作提示中显示，完成或失败后更新提示；底部保留“保存收藏”，读取期间仍禁用。

局域网 HTTP 下可创建相机参数收藏，以及上传、删除共鸣云端存档。家园标签支持多页面并发新增；删除标签后可继续编辑受影响的方案。大图切换加载完成后才允许收藏、解析、备注和方案操作；编辑备注时，方向键、Delete 和 Escape 不会触发底层大图操作，Tab 焦点保持在备注窗口内。关闭或切换参数解析窗口后，旧任务不会覆盖新状态。

云端 API 非预期错误使用结构化日志记录操作、阶段、错误类别和服务端请求 ID；错误响应的 `X-Request-Id` 可用于关联日志。日志不输出账号、令牌、请求正文或异常原文。

图片读取恢复：读取中在图片区域持续显示状态并暂禁保存；相机收藏读取失败保留旧封面或允许无封面保存，搭配替换失败保留原图，新建无图仍不可确认。失败提示独立于参数解析提示，重新选择同一文件也可重试。
桌面端左侧日期、标签和共鸣列表在内容超出可用高度时可独立滚动，顶部模块导航保持固定；手机端继续在筛选弹窗内滚动。
