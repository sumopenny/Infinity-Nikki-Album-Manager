## 功能

### 相册浏览

按“年份 > 月份 > 日期”分组浏览照片，支持缩略图比例切换、大图预览、收藏夹、最近删除、批量导入导出，以及照片/搭配方案备注与搜索。

照片备注保存会协调同站点窗口的并发写入，并检查编辑期间备注是否被修改；发生冲突时保留输入，请复制需要的内容后关闭并重新打开。若 `album-metadata.json` 损坏或版本不受支持，会拒绝覆盖，请先备份并修复文件。保存需要安全上下文中可用的 Web Locks；浏览器不支持时会提示并停止写入。

### 搭配码与参数解析

- 本地保存搭配图片、搭配码和标签，支持待填写方案、自动接收图片和 ZIP 导入导出；解析结果会按规范化搭配码缓存到浏览器。
- 输入搭配码即可解析搭配部件，点击部件可查看所属套装、进化/焕新状态与染色条件。
- 解析照片或输入 CameraParams 参数串，可查看相机、环境、画面、动作、灯光、滤镜等参数，并一键把相机参数导入游戏；文件仅在浏览器本地读取，不会上传服务器。
- 家园方案：输入家园码或组合码自动解析方案信息，支持备注、标签、封面及 ZIP 备份导入导出。

家园批量删除仅处理当前筛选结果中选中的方案，确认框显示实际数量；确认期间更改筛选不会扩大删除范围。若方案在编辑期间被其他窗口修改或删除，保存会被拦截并保留输入；请复制需要的内容后关闭并重新打开编辑器。

### 共鸣记录

从国服奇想手账或本地 JSON 导入共鸣记录，先预览再保存；按卡池展示套装及第一、二套部件抽数、总抽数与平均抽数，支持排序、星级筛选和 JSON 导出。

共鸣导入及完整备份恢复均与数据库最新记录合并，只覆盖本次导入的相同记录 ID；保留其他窗口新增的不同记录，不回写旧页面中已被删除的记录。

记录卡片的套装名与卡池名在手机和电脑上均同排显示，卡池名居右，抽数统计独立显示在下一行；长名称超出可用宽度时显示省略号，鼠标悬停可查看完整名称。

### 文件清理

专项清理低画质图片与游戏截图、崩溃快照、运行日志和游戏内置浏览器缓存。

### 小工具与帮助

抽卡吉时、更新记录、使用帮助与问题反馈。

“使用帮助与介绍”共用一个入口，中英文内容按当前布局分别展示：900px 及以上显示电脑导航、目录授权、鼠标和快捷键，窄屏显示手机底部导航、标签选择、卡片图标、触摸和备份迁移。打开帮助时改变窗口宽度也会切换内容；从更新记录进入帮助，关闭后会返回更新记录。

## 手机与窄屏使用

- 手机视图、更多、标签筛选和“⋯”操作菜单支持轻量进出动画，弹窗使用统一节奏；顶部、底部导航及卡片操作提供按压反馈，并遵循系统“减少动态效果”设置。顶部菜单和筛选窗口在退场完成后释放背景滚动，返回焦点时避开已打开的新窗口。
- 窗口宽度小于 900px 时，顶部保留与电脑版一致的“无限暖暖工具集 / 暖立方 Nikki³”品牌展示，底部导航只提供搭配码、家园方案、相机参数和共鸣四项；相机参数直接显示参数收藏，不显示顶部照片收藏/相机参数标签页，电脑端保留原收藏夹切换。手机首次进入搭配码。相册目录授权和专项清理仍需在支持的电脑浏览器中使用。
- 顶部右侧依次为放大镜搜索、视图、更多；搜索当前模块，以顶栏下方独立浮层展开，不改变顶栏高度。清除仅清空关键词，关闭保留筛选；放大镜主题色提示当前有搜索，打开视图/更多或切换模块时收起浮层。视图直接打开缩略图、主题和语言设置；手机端所有模块禁用“半尺寸 1:1”，已有半尺寸偏好在手机端显示为普通 1:1，电脑端偏好保留。相机参数收藏页和共鸣记录页采用固定布局，手机和电脑均禁用全部比例选项，主题与语言仍可切换；窗口在当前可视区域内居中，顶部固定“视图”标题及关闭按钮。“更多”集中参数解析、抽卡吉时、全部数据备份和帮助。“更多”窗口与编辑方案窗口采用相同的大小和位置，固定顶部标题和关闭按钮，下方长菜单独立滚动。
- 搭配码、家园和相机收藏的标签、结果数量、添加与导入导出入口合并为单行：添加只显示“+”，操作菜单只显示“⋯”图标，导入导出保留在菜单中；选中标签后可一键清除。点击“全部标签”或当前分类打开居中标签窗口，不再显示重复的“筛选”按钮。窗口支持搜索和双列选择，点击标签立即筛选并返回列表；窗口底部的“管理标签”模式保留删除和标签前方的拖拽排序，不再提供上下移动按钮；选择标签窗口顶部直接显示搜索框和右侧添加标签按钮，无需先进入管理模式；管理模式隐藏整个搜索和添加行，仅提供拖拽排序、删除与完成管理。关闭窗口保留当前筛选条件，清理临时搜索及管理状态；照片的日期/动作仍从原筛选面板查看。
- 共鸣同样使用单行操作栏，集中星级筛选、结果数量、“+”添加和“⋯”操作菜单；菜单保留云同步占位、清空记录及导出。点击星级入口打开居中窗口，可直接选择卡池排序、星级或套装索引；排序/星级选择后立即返回列表，清除筛选只恢复全部星级，保留排序。空记录时仍可筛选或添加，电脑端保留原布局。
- 手机卡片使用双列，600–899px 使用三列。手机和电脑的三个模块新增标签均最多 5 个字符，相机参数已有长标签和旧备份仍可使用，不自动截断。家园方案标签位于方案码右侧并同排显示；相机参数标签位于“照片解析/手动收藏”来源右侧同排显示，来源靠左、标签靠右，电脑端两者仍放在标题旁。卡片标签单行显示，长名称省略；如数据包含多个标签，只显示第一个和剩余数量。操作统一放在卡片底部并只显示图标：搭配码为复制、编辑、删除、解析，家园为复制、编辑、删除，相机参数为复制、编辑、删除、详情。图标为 18px、操作栏高 44px，等宽排列且不遮挡图片；无搭配码时复制和解析置灰，删除保留确认，搭配与家园双击卡片可查看大图。导入导出在页面操作菜单中，空列表另提供导入入口。
- 选中后的批量操作栏显示在底部导航上方；全选、导出和关联图片清理等操作直接显示，删除仍经过原有确认流程。
- 大图支持单指水平滑动翻页、双指缩放及放大后拖动；双指缩放结束不会误触翻页。手机大图底部工具栏保留至少 12px 左右留白与 20px 圆角，窄屏按钮自动换行。手机弹窗保留至少 12px 左右留白与 20px 圆角；编辑窗口固定标题及保存操作，输入区滚动，并随可视窗口高度变化避让软键盘。
- 手机相机收藏编辑器的参数码输入框使用 16px 字号，与名称输入框一致；电脑端保留 12px 紧凑字号。
- 跨设备迁移：先在电脑“更多”中导出全部数据 ZIP，再在手机“更多”中导入；手机空搭配列表也提供全部数据导入入口。
- 手机通过本地启动窗口中的 Network HTTP 地址访问时，也可导入/导出全部数据；SHA-256 校验自动使用兼容实现，备份格式保持不变。

## 搭配码管理
电脑端进入“搭配码”后会按用户偏好显示独立操作指南，也可从标题旁的指南按钮打开；手机端不展示指南入口或自动弹出指南。
- 最多可创建 40 个用户标签，每个标签不超过 5 个字符。删除使用中的标签只会让相关方案归入“未分类”。
- 新增标签会显示在标签列表首位；可拖动左侧手柄调整顺序。
- 点击“添加方案”可以选择、拖拽或粘贴图片（点击窗口空白处后按 `Ctrl+V`）；JPG 和 PNG 会在本地转换为 WebP，搭配码允许留空，标签最多选择一个，双击图片可打开预览。
- 电脑端搭配卡片右上角显示解析按钮，手机端从卡片操作菜单进入解析；未填写搭配码时按钮保持禁用。删除按钮位于解析按钮左侧，并在悬停卡片或键盘聚焦时显示。
- 可从右上角“工具”菜单打开“参数/搭配码解析”窗口，直接输入搭配码，无需先创建搭配方案；解析结果复用同一个搭配码解析窗口。
- 搭配方案大图预览的底部工具栏会显示当前标签和搭配码，并提供复制与编辑按钮。
- 网站会在当前相册中按需创建 `clothe` 文件夹来管理搭配码。<span style="color: red;">批量导入时可直接把保存好的搭配图片移动进该文件夹，回到网站页面时会自动转为待填写方案。</span>
- 删除过程中如果文件无法完整恢复，网站会弹窗列出相关方案，请手动检查当前相册的 `clothe` 文件夹。
- 使用<span style="color: orange;">自动更新搭配码</span>功能需要授权当前游戏的 `X6Game` 文件夹，可前往页面右上角当前相册下拉菜单进行授权。<span style="color: red;">使用方式是：在游戏内点击分享按钮，需要在搭配截图右下角点击框选按钮，框选完成后点击生成搭配码，再返回网页。网站只有在检测到新搭配码且游戏搭配图片的最后修改时间也已更新时才会导入；已有相同搭配码、图片未更新或找不到图片时会跳过并提示。</span>

- “导出数据”会在当前选择的相册文件夹中生成 ZIP 数据文件，并保留搭配码、标签、备注和创建时间。“导入数据”不会覆盖已有方案，重复或无效内容会跳过；导入会先校验完整备份，再分批解压和写入图片，减少大备份占用的浏览器内存。
- JPG、PNG 和 WebP 在保存前只解码校验一次；JPG、PNG 仍会在本地转换为 WebP，整个过程不会上传图片。
- 单击搭配方案可进行多选并显示底部工具栏，<span style="color: red;">搭配方案删除后不可恢复，确认前请核对方案信息。</span>

## 专项清理

点击右上角“工具”菜单中的“专项清理”打开清理窗口，使用清理功能需要授权 `X6Game` 文件夹。

支持以下清理项：

- 低画质图片和截图（`...\X6Game\ScreenShot` 与 `NikkiPhotos_LowQuality`）：游戏拍照后产生的画质较低的图片，仅删除图片文件。存在多个账号文件夹时，可选择清理全部账号或指定账号 ID。如果当前管理的相册本身是 `ScreenShot` 或 `NikkiPhotos_LowQuality`，本次清理会跳过该相册目录、只清理另一个目录，并在确认提示中说明，建议管理 `NikkiPhotos_HighQuality` 相册。
- 游戏崩溃时的快照信息（`...\X6Game\Saved\Crashes`）：删除后将无法通过本地日志向官方反馈历史崩溃原因。
- 游戏运行日志（`...\X6Game\Saved\Logs`）：删除后无影响。
- 游戏内置浏览器与登录器缓存（`...\X6Game\Saved\webcache_4430`）：清理过期网页数据，但初次打开活动页面或公告时会加载变慢。

## 选择相册

点击“选择/恢复相册路径”，推荐直接选择：

```text
...\InfinityNikki Launcher\InfinityNikki\X6Game\Saved\GamePlayPhotos\你的ID\NikkiPhotos_HighQuality
```

不要选择 C 盘、Program Files、游戏安装根目录等受保护或过大的上级目录。

| 导出全部图片 | 将当前相册全部图片复制到指定文件夹并显示进度 |
| 底栏导出 | 将选中的图片复制到指定文件夹 |

> 普通相册删除会把原图移动到当前相册的 `trash` 文件夹；<span style="color: red;">最近删除中的“永久删除”和“专项清理”会直接删除电脑文件，无法恢复。</span>

## 最近删除与刷新

- 点击“刷新相册”可立即同步文件夹；页面重新获得焦点时也会自动同步，并提示新增或外部移除的照片。
- 最近删除按删除时间排序，顶部显示照片总数和总大小；支持单张或批量恢复、永久删除、全选、大图预览和清空全部。
- 恢复时若原相册已有同名文件，会自动使用 `_restored_1`、`_restored_2` 等后缀，不会覆盖现有照片。
- 最近删除不会自动过期，会一直保留到手动恢复或永久删除。


## 常见问题

### 启动器没有反应

- 确认项目已经完整解压，不要在 ZIP 内运行。
- 确认已安装 Node.js LTS，且 `start` 文件夹没有缺失。
- 检查安全软件是否拦截 EXE 或 BAT 文件。
- 也可直接运行 `start\Start-Remote-D1-Website.bat` 查看错误信息。

### 网页没有显示照片

- 确认选择的是实际图片目录。
- 确认文件扩展名受支持；文件名以日期格式开头时会优先按文件名整理，其他图片会按文件最后修改时间显示。
- 浏览器授权失效时，重新点击“选择/恢复相册路径”。

### 浏览器拒绝打开文件夹

浏览器会阻止网页访问系统目录。请直接选择 `NikkiPhotos_HighQuality`，<span style="color: red;">不要选择磁盘根目录或游戏安装上级目录。</span>

## 隐私与安全

- 照片在本地浏览器中读取。
- 照片尾段、账号密钥派生、AES 解密和 CameraParams 解析均在本地 WASM 中执行，照片和解析结果不会上传。
- 相册目录授权、收藏记录、搭配码、家园方案码和照片动作解析缓存保存在当前浏览器本地；“更多”里的“清除缓存”会清除这三类解析缓存，不影响其他授权或设置，也不会删除已保存的方案和标签。“清除数据”经确认后重置偏好和目录授权，保留已保存的方案、共鸣记录及收藏；浏览器自身清除站点数据可能删除本地记录，请提前备份。
- 浏览器可能因安全策略要求重新授权文件夹。
- 删除和专项清理会修改电脑中的真实文件；“清除缓存”和“清除数据”不会删除电脑里的文件。

## 本地安装


环境要求：Windows、[Node.js LTS](https://nodejs.org/)、电脑上的最新版 Chrome、Edge 或其他兼容的 Chromium 浏览器。

### 安装 Node.js

1. 打开 [Node.js 官网](https://nodejs.org/)，下载标有 **LTS** 的 Windows 安装包，不要选择 Current 版本。
2. 双击安装包，保持默认选项并继续安装；确保 `Add to PATH` 相关选项没有被取消。
3. 安装完成后关闭并重新打开终端、项目文件夹和启动器窗口，让环境变量生效。
4. 按 `Win + R`，输入 `cmd` 并回车，然后分别运行：

```bash
node -v
npm -v
```

两个命令都能显示版本号，说明安装成功。如果提示“不是内部或外部命令”，请重启电脑后再试；仍然失败时，卸载 Node.js 并重新安装 LTS 版本。

### 本地部署

1. 从 [GitHub Releases](https://github.com/sumopenny/Infinity-Nikki-Album-Manager/releases) 或 [Gitee Releases](https://gitee.com/sumopenny/Infinity-Nikki-Album-Manager/releases) 下载并解压项目，或从仓库克隆源码。
2. 双击根目录的 `网站启动器.exe`。
3. 首次运行会自动安装依赖并打开 `http://localhost:5173`。
4. 使用期间不要关闭窗口。

启动器不可用时，可双击 `start\Start-Remote-D1-Website.bat`，或使用下方开发命令手动启动。根目录的 `网站启动器.exe` 也会连接这个远程 D1 启动脚本。

如果希望本地页面直接读取线上 D1 数据，请双击 `start\Start-Remote-D1-Website.bat`。点赞等 D1 请求会在本地转发到线上 Pages，不会让浏览器直接接触 D1；搭配码、家园方案数据和 Gongeo 图鉴详情由本地 Vite 直接代理到上游服务。生产部署通过 `functions/api/gongeo/[[path]].ts` 和 `functions/api/home-build/[key].ts` 提供同源数据代理。点击点赞会真实写入线上数据库，请谨慎使用。脚本默认使用 `https://infinity-nikki-album-manager.pages.dev`，也可把其他 Pages 地址作为脚本参数传入。

### 开发命令

```bash
npm install       # 安装依赖
npm run dev       # 启动前更新动作、灯光/滤镜、中英文部件目录和共鸣录映射目录，再启动开发服务器
set REMOTE_API_ORIGIN=https://infinity-nikki-album-manager.pages.dev
npm run dev:remote # 更新动作、灯光/滤镜、部件目录和共鸣录映射目录；搭配码和家园方案走对象存储代理，其余 /api 走线上 Pages
npm test          # 运行自动化测试
npm run build     # 类型检查并构建
npm run build:cloudflare # 刷新普通动作、灯光/滤镜、部件目录和共鸣录映射目录后构建
npm run resources:update:light-filters # 单独检查灯光/滤镜更新
npm run preview   # 预览构建结果
```

本地 EXE 启动器、`dev`、`dev:remote` 和 Cloudflare 构建共用资源更新链。灯光/滤镜检查暖暖相册远程热更新清单中的数据库和中英文语言包版本，版本变化时下载并校验；仅替换灯光/滤镜名称、ID 映射和图片模板，保留普通动作与大喵数据。版本相同不下载资源文件；失败时提示并沿用已有快照。普通 `npm run build` 只做类型检查和构建。

灯光/滤镜脚本支持 `--force` 强制刷新、`--strict` 在失败时终止，以及 `--manifest <URL>` / `--timeout <毫秒>`；也可用 `NUAN5_HOT_UPDATE_MANIFEST` 指定远程清单 URL、`NUAN5_HOT_UPDATE_TIMEOUT_MS` 设置超时（默认 15000 毫秒）。通过 npm 传参时在选项前加 `--`。

技术栈：Vue 3、TypeScript、Vite、File System Access API、IndexedDB。
