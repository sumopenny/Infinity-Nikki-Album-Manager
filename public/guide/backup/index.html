暖立方数据备份与跨设备迁移

根据数据类型选择模块导出、全部数据 ZIP 或共鸣云同步。切换设备、浏览器或清除数据前，先保留一份可用备份。

打开工具

四类数据如何备份？

  • 搭配码、家园方案、相机参数：使用各模块导出功能生成 ZIP，或从“更多”选择“导出全部数据”。
  • 共鸣记录：可导出 JSON，也包含在全部数据 ZIP 中；需要云端保存时另行手动上传。
  • 相册原始照片：使用相册的图片导出功能或自行备份照片文件夹。全部数据 ZIP 的范围是搭配、家园、相机收藏与共鸣，不是整个游戏相册或浏览器设置的镜像。

导入方式不同，处理规则也不同

  • 搭配、家园模块备份导入以新增和跳过重复为主。
  • 相机参数 ID 相同而内容不同时，需要选择保留本地还是导入内容。
  • 共鸣模块的普通导入用完整新记录替换全部本地共鸣记录。
  • “导入全部数据”的共鸣恢复采用合并方式，不等同于共鸣模块普通导入。
  • 共鸣上传完整覆盖云端，下载完整覆盖本地；登录和本地修改不会自动同步。

全部数据 ZIP 不包含云账号、密码或登录状态，导入也不会更新云端。要备份最新云记录，应先下载到本地再导出。

从电脑迁移到手机

  1. 在原设备导出所需模块或全部数据，确认备份下载完成；有多个文件时全部保留。
  2. 手动将备份文件传到手机，在目标浏览器打开工具。
  3. 从对应模块或“更多”的全部数据导入入口选择备份，处理冲突并查看结果。

浏览器、设备或访问域名不同，本地记录不应视为自动共享；请使用备份或共鸣手动云同步迁移。

清除缓存、清除数据之前

清除缓存只移除解析缓存。清除数据则会删除当前浏览器的方案、图片、收藏、共鸣记录、标签、UID、目录授权和设置，并重新加载；无法撤销。云端账号与存档保留，不会主动退出云端登录；电脑原始照片、游戏文件和已导出备份不会被删除。

开始使用

打开工具首页后选择对应模块或菜单入口。
